## 8. Parent / Child Concept

Parent pages establish category authority.

Child pages establish specialist authority.

Example:

Google Ads

is the parent category.

Search Ads, Display Ads and Performance Max are specialist children.

The relationship should be visible in:

- Navigation
- Content
- URLs
- Internal linking
- Keyword targeting

Parent pages include Digital Arsenal.

Child pages do not.

## 12. Service Page System

The SEO page established the master service-page system.

All service pages belong to the same visual family.

Main/parent pages use the complete system.

Child pages use the same core experience but focus tightly on their specific service.

This prevents the website from becoming a collection of unrelated landing-page designs.

---

Service artwork is part of the brand identity.

---

## 15. Scalability Model

Ideally a new service requires:

1. Route
2. Service data
3. Service-specific content
4. Metadata
5. Canonical
6. Image
7. Parent relationship if applicable
8. FAQs
9. Process
10. Arsenal only if it is a main/parent service

The shared system handles the visual structure.
